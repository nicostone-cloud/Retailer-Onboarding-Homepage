Module 04
Retailer Due Diligence Questionnaire
Before we deploy hardware, sign an MSA, or commit capital, we need to understand how a retailer operates. Their IT infrastructure determines what ConnectOS can connect to. Their data maturity determines what measurement is possible. Their procurement process determines how long CAPEX approval takes. Their security posture determines what we need to evidence. This tool generates a structured 126-question questionnaire that surfaces all of it — across commercial, technical, operational, data, and compliance dimensions — before any of it becomes a problem mid-programme.
Pre-signing 126 questions 9 sections ISO 27001 mapped Print-ready
How it works: Select retailer and question categories → generate scoped questionnaire → export or print for the discovery and due diligence pack.

Tool 07
RFP / RFI Response Assistant
A browser-based AI tool that drafts answers to retailer RFP and security questionnaire questions, grounded in BCS's ISMS, ConnectOS platform facts, and prior response library. Set the retailer name and document type, paste in a question, and get a professional draft answer back — with ISO 27001 references, correct sub-processor lists, honest positions on data residency and SOC 2, and a flag on anything that needs internal sign-off before it goes to the retailer. Requires a small backend proxy to handle API authentication securely.
Pre-signing AI-powered ISMS-grounded Prior response library Verify flags
How it works: Set retailer and doc type → paste question → get a grounded draft → copy into your response. Flags anything that needs verifying before it goes to the retailer.
